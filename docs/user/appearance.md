# Appearance

Open **Settings → Appearance** to customize how T3 Code looks on the current device.

## Chat width

Use **Chat width** to set the maximum width of messages and the composer on larger screens. The
chat still shrinks automatically when the window, sidebar, or right panel leaves less room.

The default is 768 px. This preference is stored on the current client, so the web app and desktop
app can use widths suited to their own windows.

## Glass opacity

Use **Glass opacity** to control how solid translucent interface surfaces appear. It applies to
menus, dialogs, the composer, and the main sidebar in the macOS desktop app. Higher values preserve
more of the active theme color; lower values reveal more of the native macOS sidebar material.
